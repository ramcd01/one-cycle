# Interactive prototype checklist (v6)

## User screens
- Notice search: input + Enter/search button
- Region filter: dropdown list opens; selected region filters rows
- Notice status filter: dropdown list opens; selected status filters rows
- Sort: dropdown list opens; latest/oldest ordering changes
- Pagination: page buttons change visible rows
- Notice row/chevron: opens detail page
- Sidebar: Notice list / Guide / Glossary navigation
- LH link: opens LH Apply in a new tab
- Guide cards: navigate to related screens
- Glossary search: filters list
- Glossary row: opens detail modal
- Detail back button: returns to list
- Original notice: opens modal, then LH link
- Detailed documents: opens modal
- Chat: input, Enter/send button, mock AI response
- Evidence button: opens evidence modal
- Modal close/backdrop: closes modal

## Admin screens
- Admin sidebar navigation
- All status/type/section filters: real dropdown lists
- Date controls: native date picker
- Search/reset buttons
- Pagination: changes visible table rows
- CSV downloads
- Notice collection modal/actions
- Document upload: native file picker for .hwp/.hwpx
- Document detail/reprocess actions
- Error detail/reprocess/resolve actions
- Admin profile dropdown
- Logout
